VOLT PATH ver0.924
=================
対象: Godot 4.7.x / Compatibility

概要
----
ターン制グリッド上で歩いた床を帯電させ、BATとPATHを管理して戦う小規模ローグライクです。
未帯電床は「次に踏むとBATを1回復できる有限資源」で、強いカードほど盤面の未帯電床を消費します。
全10ステージ。FLOOR 10は四つ脚の蜘蛛ボス戦です。

基本ルール
----------
・未帯電床へ移動: BAT +1、そのマスが帯電
・帯電済み床へ移動: BAT回復なし
・BAT最大: 10 / HP最大: 6
・各ステージ開始時にHP全回復。BATと手札は持ち越し
・全歩行可能床が帯電すると全面帯電の危険状態へ移行。盤面が赤/青に点滅し、プレイヤー主導の移動1回につきHP -1
・通常敵の攻撃予告は固定。次ターン発動する範囲は赤白点滅
・同士討ちはなし
・移動不可 + 有効なスキルなし + リロール不可なら1秒ごとに自動待機

カード
------
直線伝導 / BAT 2
  直線の連続した帯電PATHを伝い、最初の敵へ2ダメージ。

一斉放電 / BAT 4
  プレイヤーと接続した帯電領域上を放電。
  敵は放電PATHに入った占有マス1つにつき1ダメージ。

爆弾 / BAT 7
  盤面上の任意の帯電マスを爆心にして3×3を爆発させ、爆発範囲の床を帯電。
  帯電PATHの接続やプレイヤーからの距離は問わない。
  敵は爆発に入った占有マス1つにつき2ダメージ。

ワープ / BAT 3
  盤面上の任意の帯電マスへ瞬間移動。帯電PATHがつながっている必要はない。

ラインダッシュ / BAT 2
  連続した帯電PATHを走り、敵の占有マスを通過するたび1ダメージ。
  分岐では方向選択。Zで途中停止して発動可能。

ループ / BAT 4
  現在プレイヤーと接続している帯電PATHで閉じた輪を作る。
  敵はループ内部と、その輪を構成する帯電マスに入った占有マス1つにつき3ダメージ。
  発動後は内部床をすべて帯電。壁は囲み判定に使わない。
  複数の閉領域がある場合は←→で候補を選び、Zで発動。

被弾 / 撃破フィードバック
------------------------
・敵へのダメージは合計値を白い数字で短く表示
・1〜2DMGは敵だけが小さく反応
・3〜5DMGは強い白フラッシュ + 小さな盤面揺れ
・6DMG以上は0.06秒の短い停止 + 強い白フラッシュ + 大きめの数字 / 揺れ
・通常敵撃破時は白い収縮破裂 + 2〜4個の小さな破片 + 短いリング
・蜘蛛脚は既存の専用破壊演出を優先

手札 / リロール
----------------
・手札は3枚。同じカードは同時に出ない
・使用したカードだけ補充
・0キーでBAT 2を消費し、3枚すべてリロール
・リロール前の手札3種は抽選対象から除外し、手札に無かった残り3種へ完全交換

ステージ進行
------------
FLOOR 1: 基本追跡敵のみ
FLOOR 2: 固定砲台を追加（周囲8マスが床の位置だけに生成。壁際には出現しない）
FLOOR 3: 突進機 / 逃走機を追加
FLOOR 4: 二連蛇（2マス）
FLOOR 5: 2×2重装機
FLOOR 6: 3マス砲撃機（本体＋外周1マスの5×3が床になる位置だけに生成）
FLOOR 7: 5マス長蛇型
FLOOR 8: 十字型放電機
FLOOR 9: 3×3重戦車
FLOOR 10: 四つ脚の蜘蛛ボス
・FLOOR 4〜9は、その階で必要な大型敵が必ず出現するよう地形生成時に保証

蜘蛛ボス
--------
・画面上部の画面外に本体、盤面に3×3脚を4本配置
・初期位置は盤面内側の四隅
・各脚HP12。4本破壊でGAME CLEAR
・破壊済み脚は壊れた見た目で残り、以後行動しない / 通行可能
・行動は1本ずつ。脚の中心マスを基準に周囲8方向のどれかへ1マス移動して踏みつける
・移動先はプレイヤーとの距離が最も縮まる方向を優先。斜め移動も行う
・同じ脚は同一サイクル中に2回行動しない。生存している脚が全て1回ずつ行動すると次のサイクルへ移る
・次に移動する3×3位置を1ターン予告
・踏みつけ命中でHP -1。その後、3×3脚の外側にある最短の安全床へ弾き出される
・強制移動ではBAT取得 / 歩数加算 / 帯電付与なし
・踏みつけても床の帯電状態は変化しない
・予告中の脚を先に破壊すれば、その踏みつけはキャンセル

操作
----
矢印キー : 移動 / 照準 / 分岐選択
1〜3      : 対応する手札を選択
0         : BAT 2でリロール
Z / Enter : 決定 / 発動
X / Esc   : キャンセル
R         : 現在の階層を始めからやり直す確認
  確認画面は←→で「はい / いいえ」を選択、Zで決定、Xでキャンセル。
  地形・敵配置・手札・BAT・経過時間・歩数・被ダメージは階層入場時点へ復元。
R         : ランを最初からやり直す

HUD / フィードバック
--------------------
・左: 手札3枚 + リロール
・中央: 盤面
・右: HP / BAT / FLOOR / 未帯電残量
・HP/BATの正確な数値は白文字、分類は赤丸 / 青四角
・主人公は青い丸 + 白い向き線。青い丸はゆっくり明暗
・被弾: 赤い外周 / HUDフラッシュ / 短い画面揺れ / SE
・カード6種に専用SEと盤面エフェクト
・STAGE CLEAR表示は3秒。演出中はクリアタイムを加算しない

Web公開 / Analytics
-------------------
・Web Export presetを追加。Threads OFFでGitHub Pages互換。
・mainブランチへのpushでGitHub ActionsがLinux上でWeb Exportし、GitHub Pagesへ自動デプロイ可能。
・GA4 Measurement IDは初期状態では空欄で、Analytics送信はOFF。
・有効化時はgame_start / floor_clear / game_over / game_clearをWeb版のみ送信。
・詳細はGITHUB_PAGES_DEPLOY.txtを参照。

ファイル構成
------------
main.gd
  ラン進行、入力、カード処理、各システムの接続を統括。
  共通の敵形状・射線や地形生成はsystems側へ委譲。

systems/card_catalog.gd
  カードID、表示名、BATコスト、手札用の一行説明。

systems/sfx_manager.gd
  全SEのpreload、音量、AudioStreamPlayerの所有と再生。

systems/spider_boss.gd
  FLOOR 10蜘蛛ボスの脚生成、8方向1マス追跡、4脚行動サイクル、
  踏みつけ予告、脚破壊状態、ボス専用FXタイマーを管理。

systems/skill_fx.gd
  直線伝導 / 一斉放電 / 爆弾 / ワープ / ラインダッシュ / ループの
  エフェクト状態、時間進行、開始処理、描画を管理。

systems/enemy_system.gd
  FLOOR 1〜9の通常敵AI、攻撃予告、攻撃実行、移動判断を管理。

systems/enemy_geometry.gd
  大型敵の占有マス、占有可否、距離評価、砲撃/突進/固定砲台の射線、
  敵セル判定、当たり判定、敵移動用の経路探索を共有管理。

systems/terrain_system.gd
  ステージ開始時の外周壁 / 内部壁生成と到達可能領域の確認を管理。
  FLOOR 10では従来どおり内部壁なしの専用アリーナを生成。

systems/hud_renderer.gd
  左手札、リロール、右ステータス、未帯電ゲージ、操作ガイド、
  メッセージ、STAGE CLEAR / GAME CLEAR / GAME OVER表示を描画。
  Nodeは追加せず、main.gdの_draw()中だけ描画ヘルパーとして使用。

systems/board_renderer.gd
  床、帯電床、攻撃予告、照準、通常敵 / ボス脚、残HP、主人公を描画。
  Nodeは追加せず、main.gdの_draw()中だけ描画ヘルパーとして使用。

sfx/
  仮SE WAV。後から同名ファイルへ差し替え可能。

CHANGELOG.txt
  バージョンごとの主要変更履歴。
